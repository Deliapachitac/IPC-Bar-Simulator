# List.c - List.h
Σε αυτα τα αρχεια εχω υλοποιηση μια διπλη συνδεδεμενη Λιστα με generic τυπους
ωστε να μπορεσω να προσθεσω οτι στοιχεια θελω μεσα στην Λιστα χωρις να υπαρχουν περιορισμοι.
Εχω ορισει 2 συναρτησεις την "CompareFunc" και "DestroyFunc" οι οποιες περνουν ως ορισματα 
μεταβλητες τυπου Pointer και συγκρινουν η καταστρεφουν τα δεδομενα καταλληλα. Τις αποθηκευουμε
μεσα στο struct της λιστας για να μπορουμε να την χρησιμοποιησουμε διοτι δεν γνωριζουμε τι δεδομενα 
θα αποθηκευουμε.

# Graph.c - Graph.h 
Τον γραφο τον υλοποιησα με την βοηθεια των λιστων. Αρχικα ενα γραφος εχει μια λιστα η οποια 
περιεχει δεδομενα τυπου Graph nodes.Το Graph node ειναι ενα struct το οποιο περιεχει το id του 
πελατη (τραπεζικος λογαριασμος) και δυο επιπλεον λιστες. Η μια λιστα που ονομαζεται "outgoing" 
περιεχει τα στοιχεια της συναλλαγης που εγινε απο τον ιδιο τον πελατη προς καποιον αλλον ενω η 
"ingoing" λιστα θα περιεχει τα στοιχεια της συναλλαγης που εγιναν προς το πελατη απο καποιον αλλον.
Πιο συγκεκριμενα η μια λιστα θα περιεχει τα χρηματα που μεταφερει και η αλλη τα χρηματα που λαμβανει 
καθως και τις ημερομηνιες που εγινε η συγκεκριμενη συναλλαγη. Αυτα θα τα αντιπροσοπευσουμε σε ενα 
αλλο struct το οποιο το ονομασα vertex. Στην συνεχεια υλοποιησαμε καταλληλα τον γραφο ετσι ωστε να 
υλοποιουνται αυτα που ζηταει στην εκφωνηση, τα οποια τα εξηγω αναλυτικα στα σχολια των αρχειων.
Σημειωση:
Οι συναρτησεις destroy_node και destroy_vertex ειναι οι συναρτησεις που χρειζομαστε για την 
καταλληλη καταστροφη των graph nodes και των vertexes. Εχω βαλει σε στα σχολια τις εντολες που πιστευωα
πως θα επρεπε να κανω ομως μου βγαζει  segmentetion fault στην διαγραφη των κομβων  και δεν γνωριζω τι 
κανω λαθος.

# Hash.c - Hash.h 
Στην συνεχεια χρειαζομαστε μια δομη η οποια θα εχει κοστος προσπελασης Ο(1), το hash table και 
το υλοποιησαμε με separate chaining. Ουσιαστικα ειναι μια δομή δεδομένων που χρησιμοποιεί έναν πίνακα 
και μια συνάρτηση κατακερματισμού (hash function) για να αποθηκεύσει τα generic δεδομενα μας.
Για κάθε κλειδί η συνάρτηση κατακερματισμού υπολογίζει έναν δείκτη (index) στον πίνακα και τα αποθηκευει.
Αν δύο ή περισσότερα κλειδιά έχουν τον ίδιο index αποθηκεύονται σε μια λίστα.
